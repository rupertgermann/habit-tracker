# Habit Tracker

This context covers personal habit tracking: recurring behaviors, daily logs, progress summaries, and reflections around those behaviors.

## Language

**Habit**:
A recurring behavior the user wants to track over time. A habit can be measured as a yes/no outcome or as a count of occurrences per day.
_Avoid_: Task, goal, reminder

**Yes/No Habit**:
A habit that is considered complete when it has at least one completion on a day.
_Avoid_: Binary task, checkbox habit

**Count Habit**:
A habit that can record multiple occurrences on the same day, optionally compared with a daily goal.
_Avoid_: Counter, numeric habit

**Completion**:
A dated record that a habit happened. Multiple completions on the same date represent multiple occurrences for a count habit.
_Avoid_: Checkmark, event

**Daily Goal**:
The intended number of occurrences for a count habit on a single day.
_Avoid_: Target, quota

**Streak**:
The number of consecutive days, ending at the reference day, where a habit has at least one completion.
_Avoid_: Run, chain

**Category**:
A user-visible grouping used to organize and filter habits.
_Avoid_: Tag, folder

**Calendar Period**:
The week, month, or year window used to summarize one habit's completions.
_Avoid_: View range, date mode

**Journal Entry**:
A dated reflection connected to a habit, optionally annotated with a mood.
_Avoid_: Note, diary item

**Mood**:
The user's self-reported feeling attached to a journal entry.
_Avoid_: Emotion, sentiment
